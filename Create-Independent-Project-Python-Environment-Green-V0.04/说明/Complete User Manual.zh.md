# 创建独立项目的 Python 环境

**绿色版 V0.04：** 绿色工具请到绿色包第一层双击 `Create Independent Project Python Environment.exe`。中文说明书在看得见的「说明」文件夹，英文在旁边的 `docs`。不要用 `.lnk` 快捷方式，也不需要额外的 `.bat`。

英文名：**Create Independent Project Python Environment（green V0.04）**

绿色包「说明」文件夹里还有：

- `Complete User Manual.zh.md` — 本文件
- `README.zh.md`

英文说明书在 `docs` 文件夹。

---

## 完整使用手册

**这只是辅助工具，它不能替你安装 Python。**

如果还没装 Python，双击 `.exe` 会弹出一个小说明：请先读本手册、自己安装 Python，再点确定。主窗口这时不会打开。装好 Python 之后，再双击一次这个 `.exe`。

### 从哪里下载

只用官网。不要用来路不明的「绿色 / 破解 Python」：

- 总下载页：<https://www.python.org/downloads/>
- Windows：<https://www.python.org/downloads/windows/>

点黄色的 **Download Python**。

如果已经用 Anaconda / Miniconda 装过 Python，**不要再装一份**。请保证命令行里能找到 `python` 或 `py`（勾上 PATH，或用 Anaconda 自己的命令行）。本工具不写死本机盘符路径。

### 用哪个版本

- **建议：Python 3.11 或 3.12**（官网 Windows 安装包）
- **可以：3.10、3.11、3.12、3.13**
- **不要用 Python 2.x**

普通电脑请装 64 位（文件名里有 `amd64`）。

### 安装时

1. **勾上 `Add python.exe to PATH`。** 不勾的话，本工具经常找不到 Python。
2. 点 **Install Now**。
3. 最后一页如果出现 **Disable path length limit**，请点一下。
4. 一般不用重启；如果还是找不到 Python，先关掉所有窗口再试，或重启一次。

官网安装包已经带上本工具需要的东西。下面这些**不用**再单独下载：

| 需要的 | 用来做什么 |
|--------|------------|
| Python 本身 | 运行 `.py` |
| pip | 自带；以后在每个项目的 `.venv` 里装库 |
| venv | 自带；给每个项目建独立环境 |
| tkinter（Tcl/Tk） | 自带；显示名称窗口 |
| Windows 10 或更新 | 支持 |

### 用这个工具时不需要的

不需要 Cursor、Git、Node.js、Java、Docker、Visual Studio、C++ 编译器，也不需要先装 Flask、Playwright 这类库，就能用这个辅助工具。

创建项目时，VS Code 不是必须的。但如果你希望双击 `.py` 后在编辑器里打开、再点运行，就需要 VS Code。

已经有 Anaconda 的话，Anaconda 是可选项。

### 怎么确认 Python 已经装好

- 在开始菜单搜 **Python**，看有没有 Python 3.x，或
- 打开命令提示符或 PowerShell，输入 `python --version`。应看到 `Python 3.11`（或相近版本）。如果提示不是内部或外部命令，请重装，并勾上 **Add python.exe to PATH**。

然后回到绿色包第一层，双击 **`Create Independent Project Python Environment.exe`**。

从网上下来的文件，Windows 可能拦截。第一次双击被拒绝时：右键 `.exe` 或压缩包 → 属性 → 勾选 **解除锁定** → 确定。或者选「更多信息」→「仍要运行」。

本文件夹可以复制到这台电脑的任何位置。**不必**挨着新项目，也不必挨着 `.venv`。见下面「本文件夹和新项目的关系」。

## 怎么用这个工具

### 它做什么

给不太想用命令行的人：双击 `.exe`，输入名称，它会：

1. 新建一个项目文件夹
2. 只在这个文件夹里放一份**独立**的 Python 环境（`.venv`）
3. 在这个文件夹里留下一块板，用来装库、删库
4. 留下一个按项目生效的开关（决定**这个项目**要不要走 `.venv`）。真正改双击方式是整台电脑的，第一次会确认。

### 语言：中文还是英文

在生成窗口最上面，先选 **中文** 或 **English**，再点创建。

| 选择 | 新项目里的面板 exe | 窗口文字 |
|------|---------------------|----------|
| 中文 | `本项目环境.exe` | 中文 |
| English | `Project Environment.exe` | 英文 |

这个选择会写进项目里的 `ui_lang.txt`。以后这个项目里的窗口都跟它走。要换另一种语言，请用那个选项再生成一个新项目。

### 本文件夹和新项目的关系

这是两件分开的事：

| | 本文件夹（绿色工具） | 刚生成的项目 |
|--|----------------------|--------------|
| 里面有什么 | 第一层：`.exe`（点这个）和入口 README；中文说明书在「说明」，英文在 `docs` | 你的项目文件 + `.venv`（这个项目自己的工具箱 / 环境） |
| 放在哪里 | 整夹复制到任何地方（桌面、D 盘等） | 窗口里你选的位置 |
| 用过之后 | 可以关掉或搬走；已经生成的项目继续能用 | 环境已经在新项目里面 |

**没有**「绿色生成工具那一夹必须和新项目在同一层」的规定，也**没有**「必须挨着 `.venv`」的规定。新项目里那个名叫 `工具` / `tools` 的目录是程序自己的文件，不用点；请双击最外层的面板 exe。若你正在项目里看这份手册，请点最外层 exe。

把本文件夹拷到**另一台没有 Python 的电脑**会失败。原因写在上面，不是文件夹摆放的问题。

### 注意

- **请点 `.exe`。** 绿色版不用 `.lnk`。
- 每个新项目有**自己的** `.venv`。不要从别的项目拷 `.venv`。
- `.py` 放在 `.venv` **旁边**（或项目子文件夹里）。不要放进 `.venv`。
- 本文件夹新建的、从别处粘过来的 `.py`，规则一样。
- 项目名称里不要用这些字符：`\ / : * ? " < > |`
- 如果已经有同名文件夹，不会覆盖，会提示错误。
- 创建环境可能要几秒。提示请等待时，不要反复点创建。

### 成功之后

在新项目文件夹里打开终端，随时可以运行：

```powershell
.\.venv\Scripts\python.exe some_file.py
```

即使双击开关是关的，这一句也走本项目的环境。

## V0.04：本项目这块板

项目生成后，在那个项目文件夹**最外层**双击 **本项目环境.exe**（中文）或 **Project Environment.exe**（英文）。旁边有说明和手册。脚本等文件在 `工具` / `tools` 里，不用点。

- 最上面的勾：勾上 = 这个项目双击 `.py` 走本项目 `.venv`；不勾 = 这个项目不再要求独立环境。第一次真正改本机打开方式前会弹出确认。去掉勾只关本项目，不会自动恢复整台电脑的双击方式。
- 「恢复本机双击 .py」：从备份读回原来的打开方式（整台电脑，不只这一个项目）。
- 下面：勾常用库，或把 PyPI 上的库名粘贴进输入框（空格或逗号分开）。
- 常用名单：numpy、matplotlib、pandas、openpyxl、pygame、requests、flask、pillow。
- 下面的列表只显示你要的库。它们需要的小库也会装上，但不单独列。
- 没装完的不会出现。
- 关掉窗口会停掉当前安装。
- `pip` / `setuptools` / `wheel` 不能删。
- 只想打开窗口时，请双击最外层的 `.exe`，不要去点 `工具` / `tools` 里的 `.py`。

这块板永远不会往电脑的系统 Python 里装库。

这个面板出来之前生成的旧项目，不会自动补上。请用现在的 V0.04 工具再生成一个新项目。

## V0.02：按项目的双击开关

开关文件（`use_project_env.on`）属于**一个项目**。Windows 的双击挂钩一旦改过，就是整台电脑的。

生成窗口里有一项（默认不勾）：

**在此项目中，双击 .py 时使用本项目的独立环境**

| 生成这个项目时 | 在这个文件夹里双击 `.py` |
|----------------|--------------------------|
| 勾了，并且确认了改本机打开方式 | 这个项目走本项目 `.venv`（整机双击会先经过开门程序） |
| 没勾，或取消了新挂钩确认 | 这次不写**新**挂钩。若发现旧死命令，确定会清掉后再创建；取消则不创建。若以前已经确认过挂钩，双击仍先经过开门程序，再改走备份 |
| 文件不在任何已启用的独立环境文件夹里 | 开门程序先跑备份；备份没有再试 VS Code / 记事本 |

项目 A 和项目 B 各有各的开关。去掉勾只关那一个项目。

### 当时没勾，后来改主意

不用重建文件夹。打开面板 exe，勾最上面那一项。如果这是第一次改本机打开方式，会再问一次。

别的项目的开关不受影响。要恢复整台电脑原来的双击方式，点「恢复本机双击 .py」。

### 工具在背后装了什么

Windows 不能只给某一个文件夹改「双击 `.py`」。**只有你勾选了独立环境、并且确认之后**，才会在用户 AppData 下放开门程序，并改这一项：

`HKCU\Software\Classes\VSCode.py\shell\open\command`

原来的打开方式会备份。开门程序只看**那个项目**有没有启用文件（`use_project_env.on`）。项目没启用时，双击仍会先经过开门程序：这个项目不会强制走 `.venv`，但整台电脑的打开方式要按面板上的「恢复本机双击 .py」才能改回备份。未勾选时，创建项目**不会写新挂钩**。若发现旧死命令，确定会清掉；取消则不创建。

双击编辑需要已安装 VS Code。找不到 VS Code 时，开门程序会尝试备份里的原命令；再不行会用记事本打开，避免文件打不开。也可用「成功之后」里的终端命令。

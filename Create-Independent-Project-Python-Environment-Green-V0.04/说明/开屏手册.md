# 开屏手册（V0.04）

给第一次打开绿色工具的人看。这里只讲**生成窗口**（双击绿色 exe 后出现的那一块）。项目建好之后的开关、装库，见绿色包「说明」文件夹里的 `产品功能手册.md`。英文手册在旁边的 `docs`。

绿色 exe 文件名：

**Create Independent Project Python Environment.exe**

不要用快捷方式（`.lnk`）。解压或复制整个绿色文件夹后，直接双击这个 exe。

---

## 开屏之前：电脑上要有 Python

这个 exe 只是窗口。真正给每个项目建 `.venv` 的，是电脑上已经装好的 Python。

- 如果找到了 Python：主窗口会打开。
- 如果没找到：先弹出「没有找到 Python」，请先按「说明」文件夹里的 `Complete User Manual.zh.md` 自己安装，点确定后去装。装好再双击一次这个 exe。主窗口这时不会出现。

Windows 可能提示无法识别（未签名）。如果信任这个文件：更多信息 → 仍要运行。

---

## 窗口从上到下有什么

窗口标题：`创建独立项目的 Python 环境 V0.04`

| 位置 | 控件 | 做什么 |
|------|------|--------|
| 第 1 行 | 语言：中文 / English | 决定**新项目**里面板的文字和文件名。默认中文。 |
| 第 2 行 | 项目名称 | 新文件夹的名字。不要用 `\ / : * ? " < > \|` |
| 第 3 行 | 保存到文件夹 + 浏览… | 新项目放在哪一层。默认是用户目录下的 `Projects`（没有这个文件夹就用用户主目录）。 |
| 第 4 行 | 勾选：「在此项目中，双击 .py 时使用本项目的独立环境」 | **默认不勾。** 不勾 = 只建项目，不写新挂钩。若有旧死命令会先问。 |
| 第 5 行 | 按钮「创建项目」 | 开始建文件夹和 `.venv`。进行中按钮会暂时不能点。 |
| 最下面 | 状态一行 | 空闲 / 请等待 / 没有成功 / 完成 |

换语言立刻改这一窗的文字。语言会写进新项目的 `ui_lang.txt`。以后要另一种语言，请用那个选项再生成一个新项目。

## 点「创建项目」之后会怎样

1. 名称空、有禁字符、以点/空格结尾、Windows 保留名（`CON`、`NUL`、`COM1` 等）、保存位置还不存在、或已经有同名文件夹：弹出「没有成功」。失败会删掉这次新建的目录。
2. 若注册表里 VSCode.py 仍指向本工具开门程序（旧死命令）：先问。确定：清掉后再创建（开关不打开）。取消：**不创建**。
3. **没勾**独立环境，且没有死命令：直接创建。不写新挂钩。若以前已经确认过挂钩，也不会自动拆掉。
4. **勾了**，而且本机实际打开 `.py` 的不是 `VSCode.py`（记事本、`Python.File` 等），也没有死命令：弹出「没法改双击」，项目仍创建，开关不打开。
5. **勾了**，本机走 `VSCode.py`，但打开方式还不是本工具：先弹出确认窗「将改整台电脑的双击 .py」。
   - 确定：创建项目，并改 `HKCU\Software\Classes\VSCode.py\shell\open\command`，原值备份。
   - 取消：仍然创建项目，但勾会打回去，不改双击方式。
6. 命令已是本工具开门程序、但本版本还没确认过：勾选会再问一次。确定只记下确认，不重写命令。
7. 本版本已经确认过挂钩：勾上只会给这个项目写下启用文件，并确保开门程序文件还在，不再弹确认、不再重写注册表。
8. 成功：弹出「完成」，告诉你路径、该双击哪个面板 exe，以及这次做了什么。

创建时请等待，不要反复点。

## 成功之后新项目里有什么（开屏会提到）

- 请双击 **`本项目环境.exe`**（英文项目是 **`Project Environment.exe`**）打开这块板。
- 旁边有 `说明.txt` / `Read me.txt`，以及 `使用手册.md` / `User Manual.md`。
- 脚本和辅助文件在 **`工具`**（英文项目是 **`tools`**）里，不用点。
- `.venv`：这个项目自己的 Python。`.py` 放在它**旁边**，不要放进去。
- 可选：`use_project_env.on`（只有勾选并成功启用时才有，给开门程序看的）

打开这块板之后怎么用，见 `产品功能手册.md`。

---

## 开屏不会做的事

- 不会装系统 Python，也不会往系统 Python 里装库。
- 未勾选、或你取消了「新挂钩」确认：不会新写双击挂钩。若发现旧死命令，确定会清掉；取消则不创建。
- 没有右键菜单「用项目环境打开」。
- 不会自动打开 VS Code。

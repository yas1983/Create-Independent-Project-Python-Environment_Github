# 方案与源代码（按版本阅读）

这个文件夹和绿色版 **平级**，只放方案和源码，方便对照版本阅读。  
**不要**在这里双击 exe。绿色软件在：

- `Create-Independent-Project-Python-Environment-Green` → V0.01
- `Create-Independent-Project-Python-Environment-Green-V0.02` → V0.02
- `Create-Independent-Project-Python-Environment-Green-V0.03` → V0.03

## 怎么读

1. 先看根目录的 `方案.md`（现在这套工具要做成什么样）
2. 再进对应版本的子文件夹看源码

| 版本 | 绿色 exe 在哪 | 源码在哪 |
|------|----------------|----------|
| V0.01 | `Create-Independent-Project-Python-Environment-Green` | `V0.01/` |
| V0.02 | `Create-Independent-Project-Python-Environment-Green-V0.02` | `V0.02/` |
| V0.03 | `Create-Independent-Project-Python-Environment-Green-V0.03` | `V0.03/` |

## 以后每出一个绿色新版本

不要擅自升号。只有 yas 明确说升级时，才同时做两件事：

1. 新建绿色文件夹，例如 `Create-Independent-Project-Python-Environment-Green-V0.04`
2. 在**本文件夹**里新建 `V0.04/`，放入该版本完整可读源码，并写一页 `README.md` 说明这一版改了什么

日常修改先改**当前版本**（现在是 V0.03）的源码，并更新对应绿色 exe。绿色 exe 文件夹里只留：exe、README、Complete User Manual。源码不放进去。

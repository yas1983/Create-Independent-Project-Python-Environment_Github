# 维护本项目的库

窗口体验已定。装库规则：

- 下面的列表只信这个项目 `.venv` 里 pip 的真实结果
- 没装完、没能 import 成功，不算已安装
- 强行关窗口会停掉当前安装；半截不会写成「已安装」
- 再装时若有半截残留，会强制重装一次，避免「以为装上了其实没有」或「再也装不上」
- pip / setuptools / wheel 不能删

快捷项：numpy、matplotlib、pandas、openpyxl、pygame、requests、flask、pillow。  
上面没有的，可在输入框粘贴库名（空格或逗号分开）。

这个入口以后放进**生成出来的项目文件夹**。在本预览目录运行时旁边没有 `.venv`，不会真的上网装包，但中断规则一样。
